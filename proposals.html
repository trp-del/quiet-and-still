Quiet & Still · proposals · November 2026

The chrome has receded. Here are ten ways to make the quiet work harder.

The plugin already sets every element to one of three volumes. The next gains are about when volume changes, what earns it back, and whether people can still find and learn what has gone quiet. Every proposal below keeps the ten rules in RULES.md; each says which ones it extends and how it would ship. The demos run at Still's real levels: whisper 0.12, quiet 0.4, amber for live state only.

Arriving

The first second on a page, and the pointer passing through.

01

Orient, then recede

When a page opens, the chrome shows at full volume for one beat, then fades to its level. You get a glance at where you are and what is around you, and then it gets out of the way.

Why it helps. Whisper-level chrome is hard to locate cold. One orienting glance builds the spatial memory that lets you reach for it later without looking.

New element chrome.orient: add a class on route change, drop it after 900 ms. The fade back stays 150 ms on opacity.

02

Dwell before reveal

A region restores only after the pointer rests on it for about 140 ms. Pointers crossing the sidebar on the way to the dock or the window edge no longer make it flash.

Why it helps. An unrequested reveal pulls the eye just as much as a notification does. Hover intent separates "I'm going there" from "I'm passing through".

Extends
4Attention restores volume10Calm motion
Ships as
One token, --qs-dwell: 140ms, used as transition-delay on every hover state. Fading back out keeps no delay. Focus restores at once.

Working

Writing and editing: knowing where you are, and what's there when you need it.

03

Peek key

Hold a key and everything returns to full volume. Let go and it recedes again. It works the same everywhere, so the quiet never has to be undone in settings.

Why it helps. Fading is easier to trust when it can be reversed instantly. It gives keyboard users the same "attention restores volume" that hover gives the mouse.

Extends
2Fade, never remove4Attention restores volume
Ships as
A configurable hold key plus a command "Quiet & Still: peek". JS toggles html.qs-peek; one CSS rule sets the levels to 1.

04

Lit branch

The thread lines and bullets on the path to the block you're editing rise from whisper to quiet. The rest of the outline stays as it is. Text is never dimmed.

Why it helps. In a deep outline it's easy to lose which parent you're under. The lit path answers that without breadcrumbs or a box, and it's live state, not a category.

05

Empty is quieter than full

Empty property values, the --- placeholder, "Add property" and the trailing empty bullet drop to whisper. Filled properties stay quiet. A glance at the property area now shows what is known.

Why it helps. Placeholders look like data, so the eye reads them as data. On the Fatigue page, three of four property rows are empty and they all compete equally today.

06

First mention carries the line

The first time a page is referenced on a page, its underline is full strength. Later mentions keep the same dotted line at whisper. They are still clearly links, just no longer repeated news.

Why it helps. Writers say "given, then new". Five underlined Dr. Mei Chens down a column make a pattern that the eye keeps scanning. One per page is enough to say "this is a link".

Noticing

The few things that should break the quiet, and only while they matter.

07

Time is state

A date due today or overdue takes the amber Still already reserves for live state. Dates further out step back to quiet. Nothing new is added to the palette.

Why it helps. All dates look the same today, so you have to read each one to find what's pressing. Overdue is the most live state a date can have.

Extends
7Color is scarce8State beats category
Ships as
JS compares scheduled and deadline values to today and adds data-qs-when. It reuses --qs-state, so the four-hue budget holds.

08

Status speaks on change

Sync and saving indicators whisper while things are fine. When something needs you, the indicator rises to full volume in the state hue and a notice fades in. It doesn't slide or bounce.

Why it helps. A green dot that is always on teaches the eye to ignore it, and then it gets ignored when it turns red. Silence while steady makes the change easy to see.

Extends
8State beats category10Calm motion
Ships as
CSS on the header sync indicator and the notification container. It overrides their slide-in with a 150 ms fade.

Trusting

Quiet only works if people can still find things and learn what the keys mean.

09

A floor for findability

"Fade, never remove" needs a measurable floor. The build clamps each system's whisper so faded chrome keeps at least 1.5:1 contrast in both themes. It also honours prefers-contrast: more and prefers-reduced-motion.

Why it helps. Still's whisper of 0.12 measures about 1.25:1 on white and 1.34:1 on Logseq's dark background, so it is already below that floor. Below it, a whisper is effectively removed.

10

The key, on demand

A command shows the current system's legend: each type, its channel, and a sample. Pointing at a row drops everything else to whisper so only that type stays lit.

Why it helps. "Just noticeable" keys are only quick once you've learned them. Dotted versus dashed is easy to miss until someone shows you. The data is already there: each system declares keys.

Ships as

Considered and set aside

Ideas that sound calm but break a rule.

Typewriter dimming

Dimming every block except the one you're editing breaks rule 1: block text keeps full ink. The lit branch (4) gives the same sense of place without taking volume from content.

Hide chrome while typing

Hiding chrome while you type breaks rule 2: if you can't see it exists, you can't reach for it. Dwell (2) and the peek key (3) handle that without removing anything.

Tint blocks by depth

Coloring each level of nesting would spend hue on category, not state, and exceed the four-hue budget. That breaks rules 7 and 8.
